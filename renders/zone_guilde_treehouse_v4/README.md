# ZGT4 — village généré avec texture de référence 8px

`ZGT4_village_imagegen.png` est le rendu imagegen original. `ZGT4_village_768x576_palette_T00P01.png` est le même concept ramené au canvas 768×576 (96×72 cases de 8px) et mappé sur la palette RGB de T00P01.

Le concept s'appuie sur le layout ZGT2 et les références locales T00P01/Halcyon pour les textures, le rythme et les fleurs. Les fleurs sont une création originale inspirée de la palette et de l'échelle; elles ne copient pas les pixels natifs.

ZGT4 reste une image de concept, pas un calque PMDO ni une extraction exacte de textures. La composition PMDO multicalque en 8 parties, avec échantillons canonique T00P01, reste fournie en ZGT2 (`renders/zone_guilde_treehouse_v2/ZGT2_layers.ora`, `ZGT2_PMDO_0812.zip`).

# ZGT3 — concept généré par image

`ZGT3_concept_imagegen.png` est un concept d'image généré à la demande, à partir du layout ZGT2 et d'une référence florale Halcyon/Palikadude conservée dans le dépôt (`Vast_Steppe_Flower_Animations.png` / `Halcyon_flower_reference.gif`). Les grappes de fleurs sont originales et reprennent seulement l'ambiance de couleurs et la densité de la référence; les pixels natifs Halcyon ne sont pas copiés dans cette image.

Image 1200×896, RGB, statique. C'est une illustration de composition, pas une carte PMDO importable, une texture canonique ou un tilesheet. ZGT1 et ZGT2 restent inchangées.
